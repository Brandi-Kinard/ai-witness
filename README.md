# AI Witness

Pronounced "eye witness." The name is literal. Experienced on smart glasses, it's a tool that sees what you see, so the AI is a witness alongside you, not a separate camera pointed at you. Point it at raw footage and it hands back a first draft of a written story: headline, tags, and a draft article grounded in the actual photos, video, and audio it captured. You edit and approve everything before it is published.
